# Índice de herramientas

**Fuente de verdad del inventario de herramientas y de su estado.** Nada se marca
✅ OK hasta que el usuario confirma explícitamente que funciona.

Listado de módulos y herramientas del servidor, con su firma y comportamiento.
Todas las herramientas COM siguen el patrón `async def` + `_run()` interno +
`run_com(_run)`; los errores devuelven `{"error": "..."}` en vez de lanzar
excepciones.

## `scripts\templates\`

Plantillas Python listas para ejecutar contra Civil 3D via COM (pywin32),
sin pasar por el servidor MCP. Todas usan `GetActiveObject` (nunca `Dispatch`)
y `try/except`.

| Ruta | Operación |
|---|---|
| `scripts\templates\borrar_objeto_por_handle.py` | Borra un objeto del ModelSpace por su handle hex |
| `scripts\templates\crear_circulo.py` | Crea un círculo en el ModelSpace en capa y posición indicadas |
| `scripts\templates\cambiar_capa_objetos_por_handle.py` | Cambia la capa de uno o varios objetos por handle |
| `scripts\templates\copiar_objeto_con_desplazamiento.py` | Copia un objeto y lo desplaza con vector dx/dy/dz |
| `scripts\templates\crear_puntos_cogo_desde_lista.py` | Crea puntos COGO desde lista; usa `GetInterfaceObject` + VARIANT `[Este, Norte, Elev]` |
| `scripts\templates\borrar_puntos_cogo_por_numero.py` | Borra puntos COGO por número de punto |
| `scripts\templates\editar_vertices_polilinea.py` | Reemplaza vértices de polilínea 2D o 3D por handle |
| `scripts\templates\analisis_conectividad_extremos.py` | Detecta extremos libres y pares conectados entre polilíneas |
| `scripts\templates\acotar_bloque_seccion.py` | Acota con MLeaders de nivel (Z real) un bloque de sección generado; interseca el plano de corte con las aristas 3D del modelo y calibra el bloque 2D. Incluye el LISP para volcar `Section.Vertices` (ilegible via COM externo) |
